B3 VM herunterladen

Eine fertig eingerichtete Linux-VM für den Unterricht. In zwei Schritten auf deinem PC.

Schritt 1: Herunterladen

Lade die VM herunter, eine .ova-Datei mit etwa 8 GB. Ein Server wird automatisch für dich ausgewählt.

Andere Download-Quelle wählen
  • Google Drive Öffnen
  • ByCS Drive Passwort Ab!1234567 Öffnen
  • OneDrive mit Schulkonto Öffnen

Schritt 2: Installieren

VirtualBox installieren, die VM importieren, starten. Die Anleitung zeigt es Schritt für Schritt.
